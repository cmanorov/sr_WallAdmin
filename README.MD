# 🧱 Studio Reborn Wall Admin

Sistema avançado de Wall / ESP administrativo para FiveM com foco em:

* Performance
* Renderização otimizada
* Interface moderna
* Compatibilidade multi-framework

---

# ✨ Funcionalidades

* 👁️ Visualização de jogadores
* ❤️ Vida e colete em tempo real
* 🏷️ Tags de Staff / Invisível / Wall
* 🔫 Arma equipada
* 🚗 Veículo atual
* 📏 Traçados até jogadores
* 🖥️ Interface NUI moderna
* ⚡ Sistema otimizado para alta população

---

# 📦 Compatibilidade

Suporte nativo para:

* QBOX
* QBCore
* ESX
* vRP
* Standalone

---

# 📥 Instalação

Adicione o resource na pasta:

```text
resources/
```

Depois no `server.cfg`:

```cfg
ensure sr_walladmin
```

---

# 🎮 Utilização

Comando:

```text
/wall
```

---

# 🧠 Estrutura

```text
sr_WallAdmin/
├── client/

```
